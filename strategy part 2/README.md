This folder is the plain-language method for the Jarvis desk. The file is `THE_METHOD.md`.

The heavier timeframe permits the side. The lighter timeframe times the bar. A pullback is the fast sensor dipping against a heavier clock that is still intact, then rejoining. A continuation is both clocks already aligned and price leaving with them. One chart cannot tell those two apart.
